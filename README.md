# Floating Timer

A lightweight floating desktop timer for windows

Floating Timer supports both stopwatch and countdown modes in a small always-on-top window.

## Features
-Stopwatch mode
-Countdown timer
-Start / pause
-Reset
-Edit countdown duration
-Add 1 minute to countdown
-compact mode
-Always-on-top floating window
-System tray controls
-Window installer

## Download
Download the latest Windows installer from the 
[Release](../../releases) page

## Installation
1. Download the `Floating Timer Setup.exe` installer.
2. Run the installer.
3. Choose the installation location or stay with default.
4. Launch Floating Timer.
